# AI 模型规划（双轨方案）

## 1. 总体策略

```text
轨道 A（保底，先做）    轨道 B（亮点，后做）
CPU Cube.AI 推理        NPU/ATON 推理
· 模型小、可快速集成    · 吞吐高、功耗低
· 跑通演示闭环          · 体现 M55 NPU 能力
```

## 2. 模型选型（候选）

| 任务 | 候选模型 | 说明 |
|------|---------|------|
| 人脸检测 | 轻量 SSD / MobileNet-SSD | 输出人脸框 |
| 眼部关键点 | 轻量 landmark（5-6 点） | 计算视线方向 |
| 眨眼检测 | 基于 EAR（纵横比） | 无需深度模型，规则可做 |
| 备选：方向分类 | 小型 CNN（左/右/上/下/中心） | 端到端方向输出 |

## 3. 数据与训练

- **数据来源**：`models/dataset/`（自采 + 开源人脸数据集）
- **训练**：`models/training/`（脚本 + 训练日志）
- **导出**：`models/exported/`（TFLite/ONNX）
- **Cube.AI**：`models/cubeai/`（ST 工具链转换输出）

## 4. 工程化要点

- 输入图像：灰度或 RGB，ROI 裁剪后缩放（如 96x96 / 128x128）
- 预处理实现：`app/examples/eye_cam/`（`build_taps` 多相重采样，与训练端 `PIL.BILINEAR` 逐点对齐）
- 量化：INT8 量化以适配 NPU
- 评测指标：识别准确率、帧率（FPS）、单帧延迟

> 注：若 DCMIPP+IMX335 集成受阻，保底使用**外部视觉模块**（串口/UART 上报动作事件），系统仍可闭环。
