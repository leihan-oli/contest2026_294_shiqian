# 系统架构

## 1. 总体架构（三层）

```text
┌─────────────────────────────────────────────────────┐
│  应用层  app/eye_control（LVGL UI + 状态机）          │
│  · 看左/看右/看上/看下 → 光标/翻页                    │
│  · 眨眼/闭眼 → 确认/长按                              │
└──────────────────────┬──────────────────────────────┘
┌──────────────────────┴──────────────────────────────┐
│  openvela（NuttX）平台层                              │
│  · LTDC framebuffer + LVGL（显示）                   │
│  · DCMIPP + IMX335（图像）→ 经输入驱动上报            │
│  · AI 推理（CPU Cube.AI 优先，NPU/ATON 跟进）         │
│  · 外设驱动（LED/GPIO/PWM/串口）                     │
└──────────────────────┬──────────────────────────────┘
┌──────────────────────┴──────────────────────────────┐
│  硬件层（ATK-DNN647）                                 │
│  STM32N647X0H3G · 外部 NOR（FSBL+app） · 外部视觉     │
└─────────────────────────────────────────────────────┘
```

## 2. 眼控数据流

```text
摄像头(DCMIPP/IMX335)
   → 图像帧（RGB/YUV）
   → ROI 预处理（按脸框裁剪 + 多相重采样，app/examples/eye_cam）
   → AI 推理（人脸/眼部关键点 或 眨眼检测）
   → 动作事件（看左/看右/眨眼/闭眼）
   → 状态机（eye_control_state_machine）
   → 控制指令（LVGL UI 操作 / 外设 GPIO/PWM）
```

## 3. 关键设计决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| 图像采集 | 优先 DCMIPP + IMX335 | 硬件 ISP、平台原生支持 |
| AI 推理 | 双轨：CPU Cube.AI → NPU/ATON | 先保证可用，再追求性能亮点 |
| 启动 | 自定义 FSBL（LRUN+RIF）→ NOR Flash | 脱离 ST 官方 BootROM 限制，大赛亮点 |
| UI | LTDC + LVGL | 轻量、适合 M55 单核 |

> 详细决策记录见 [adr/](adr/)。
