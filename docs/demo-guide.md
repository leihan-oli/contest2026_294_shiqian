# 演示指南

> 目标：一套"**看着屏幕就能操作**"的无接触控制演示，评委可上手体验。

## 1. 演示场景（默认）

1. 上电 → 外部 NOR Flash 自动启动 → LVGL 界面出现（眼睛看向屏幕）
2. 屏幕显示 **3x3 图标网格**（灯、风扇、音量、返回…）
3. 操作者**看向**目标图标 → 高亮跟随移动
4. **眨眼** → 确认选中 → 外设动作（LED 亮/灭、蜂鸣器、串口指令）
5. **闭眼保持** → 返回上级 / 关机菜单

## 2. 演示清单

- [ ] 启动演示（Flash boot，≤10s 出界面）
- [ ] 方向控制演示（看左/右/上/下移动光标）
- [ ] 眨眼确认演示（控制 LED/外设）
- [ ] 防误触演示（快速眨眼不触发）
- [ ] 掉电/复位演示（数据与启动稳定性）

## 3. 演示脚本（示例）

```text
[开机] 绿 LED 闪烁 3 次 → LVGL 主界面
[观众] 看向"灯"图标 2s → 高亮
[眨眼] → 灯图标高亮确认 → LED0 点亮
[观众] 看向"风扇" → 高亮 → 眨眼 → 串口输出 FAN_ON
[闭眼保持] → 返回主菜单
```
